# 🏥 Healthcare Data Analysis & Dashboard

## 📌 Project Overview

This project focuses on analyzing a healthcare dataset containing **10,000 patient visit records** to uncover meaningful insights related to patients, doctors, diagnoses, treatments, follow-ups, and healthcare operations.

The project involved working with raw healthcare data, organizing and analyzing the information, creating KPIs and pivot tables, and developing an interactive dashboard to support data-driven decision-making.

## 🎯 Objective

The main objective of this project was to transform raw healthcare data into meaningful business insights and answer questions such as:

* How many patients and doctors are included in the dataset?
* Which diagnoses are most common?
* What is the monthly trend of patient visits?
* Which doctor specialties handle the highest number of visits?
* How many patients require follow-up?
* What are the major treatment and diagnosis patterns?
* How can healthcare data be presented through clear and useful visualizations?

## 📊 Key Analysis

The analysis included:

* **10,000 patient visits**
* Patient demographic analysis
* Diagnosis-wise patient analysis
* Monthly visit trends
* Doctor specialty workload analysis
* Follow-up requirement analysis
* Treatment and medication analysis
* Laboratory test analysis
* Patient age-category analysis
* Healthcare KPI development

### 🔑 Key KPIs

Some of the important KPIs identified in the project include:

* **Total Patients:** 10,000
* **Follow-up Required:** 4,984 patients
* **No Follow-up Required:** 5,016 patients
* **Top Diagnosis:** Asthma – 2,009 cases
* **Highest Doctor Workload:** General Medicine – 2,170 visits
* **Cardiology:** 2,068 visits
* **Orthopedics:** 1,846 visits
* **Neurology:** 1,824 visits
